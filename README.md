# Premium E—Invitation 

A collection of invitation templates by **Premium E-Invitation**, featuring three invitation formats:

- **For free cards:-** https://premiumeinvitations.vercel.app/
- 💌 **Digital Invitations (Free)** — static invitation card designs
- 🎬 **Animated Invitations** — motion-based invitation designs
- 🌐 **Web Invitations** — interactive invitation websites

## Categories

Templates can cover a wide range of events, including:

- 💍 Wedding
- 🎂 Birthday
- 💖 Engagement
- 👶 Baby Shower
- 💐 Anniversary
- 🎉 Party
- 🏠 Housewarming
- 👶 Naming Ceremony
- 💒 Reception
- ✨ Other special events

## Usage

### Digital Invitations
Use the provided invitation design as a base and customize the required event details.

### Animated Invitations
Open the template files in a compatible browser/editor and customize the available content.

### Web Invitations
Open the web invitation's `index.html` in a browser, or deploy the folder using a static hosting service such as GitHub Pages.

## Customization

Depending on the template, you may be able to customize:

- Names
- Event date and time
- Venue
- Photos
- Colors
- Text and other event details

## Free Templates

This repository is intended to provide free invitation templates for personal event use. Check each template's included notes or license information before redistributing or using it commercially.
